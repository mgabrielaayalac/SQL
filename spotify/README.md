# Spotify Track Analysis

**Question:** Which artists and tracks score highest on popularity, danceability and energy?

**Data:** Spotify track data from Kaggle, loaded into a table I created.

**SQL used:**

- Table design with typed columns
- Loading a CSV into SQL
- Aggregations by artist and track
- Ranking with `ORDER BY` and `LIMIT`
