# Fortune 500 Benefits Analysis

**Question:** How do employee benefits, paid time off and revenue compare across industries?

**Data:** A table of companies with industry, revenue, headcount, healthcare benefits, paid time off, maternity leave and tenure.

**SQL used:**

- Table creation and data loading
- `CASE` to segment companies by maternity leave
- `GROUP BY` with `HAVING`
- Filtering and ranking
