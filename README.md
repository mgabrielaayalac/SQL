# Gabriela Ayala: SQL Portfolio

SQL I have written to analyze customer, sales and audience data. Each project has its own folder with the code and a short write-up of the question, the data and the SQL used.

## Projects

| Project | What it answers | SQL used |
| --- | --- | --- |
| [Electronic Store Customer & Order Analytics](electronic-store-orders/) | Monthly order volumes, revenue by product and store location, and how much customers who buy more than two items spend | Joins across customer and sales tables, aggregations, subqueries, data-quality filters |
| [Chinook Music Store Analysis](chinook-music-store/) | Customers, invoices and total sales by sales agent in the Chinook music store database | Multi-table joins, filtering, grouping, ranking |
| [Climate Conference Analysis](climate-conference/) | Which VIP attendees booked hotels, RSVP'd to events and gave feedback | LEFT, INNER, multiple and self joins, subqueries |
| [Fortune 500 Benefits Analysis](fortune-500/) | How company benefits, paid time off and revenue compare across industries | CASE segmentation, GROUP BY with HAVING, filtering |
| [Spotify Track Analysis](spotify/) | Average popularity, danceability and energy by artist and track, and the top 10 tracks by popularity | Table creation, data loading, aggregations, ranking |
| [Superstore Pricing Analysis](superstore/) | How item prices vary overall and by category | Table creation, sorting, summary statistics |
