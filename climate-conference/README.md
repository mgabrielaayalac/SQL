# Climate Conference Analysis

**Question:** Which VIP attendees booked hotels, RSVP'd to events and gave feedback, and which events drew the most attendees?

**Data:** A conference database of VIPs, reservations, hotels and events ([DB Fiddle](https://www.db-fiddle.com/f/pxMci1sLL945KHKYvpe9W6/1)).

**SQL used:**

- `LEFT`, `INNER` and self joins
- Joins across several tables
- Subqueries
- Attendance counts with `GROUP BY`
